# Cognitive Core v1.0：理论先于系统

> 状态：**理论设计稿**；不是扫描程序、交易信号或已经运行的 Agent。更新日期：2026-10-09。
> 上游原始依据：用户提供的《万维钢·现代思维工具100讲》Skill v2.0、Crypto Market Alpha OS Skill v4.3。
> 只建立理论底座，不在本阶段修改 Radar、扫描币、接行情、增加自动交易。

## 一、什么是这个系统

目的不是“使用尽量多的理论”，而是让每一次重要判断留下可检验的产物：
**问题 → 可比选项 → 主机制 → 证据与反证 → 判断 → 可承受行动 → 事后验证 → 修正规则**。

系统由四个彼此独立的理论引擎构成：
1. **世界模型 World Model**：对象、参与者、资源/存量、流量、激励、时间延迟和反馈。回答“为什么变化”。
2. **认识论 Epistemics**：可验证事实、推断、假设、未知、参考类、贝叶斯更新、证据诊断性。回答“凭什么相信”。
3. **决策论 Decision**：目标、可行选项、信息价值、机会成本、可逆性、尾部风险、生存约束。回答“该不该行动”。
4. **学习论 Learning**：可结算预测、事前记录、失败样本、后验校准、指标失真和版本变更。回答“怎么知道自己在进步”。

每轮只启用 **1 个主思维工具和至多 3 个补充或反证工具**。工具选择取决于问题类型，不是固定把13个理论全部跑一遍。简单机械任务不启用。

## 三、最小世界模型：先解释机制

每个重要研究问题必须尝试写出：
- **边界**：研究对象、市场、用户与时间跨度；
- **参与者**：谁决策、谁出资、谁承担风险、谁受益；
- **存量**：资本、用户、信誉、技术能力、流动性；
- **流量**：新增、迁移、退出、费用、损耗；
- **激励**：同一动作对不同参与者的收益和代价；
- **反馈**：哪些变化自我增强，哪些力量纠偏；延迟多长；
- **竞争/替代**：谁能绕开价值链中的关键环节；
- **可证伪性**：什么观察结果证明模型方向错了。

画出因果箭头只是**工作假说**，不是已经证明的因果关系。

## 四、认识论：事实不等于故事

证据分五栏：
1. **事实**：可追溯原始来源、时间戳及采样口径。
2. **推断**：从事实推出的解释及其前提。
3. **假设**：尚未验证的关键命题。
4. **未知**：缺什么、缺失是否改变结论。
5. **反证**：支持另一解释或推翻当前机制的材料。

判断更新：
- 先定义可比较假设和**参考类**；
- 研究新证据对各假设是否具有**区分力**；
- 证据共源、关联、重复转载时不能重复计权；
- 没有可靠样本和似然信息时，使用定性区间而不是捏造精确后验概率；
- 预先写明出现何种证据才更新结论；
- 真正不确定时允许写“暂不判断”。

## 五、决策论：把“不做”作为基准

总是比较至少三个状态：**不行动/维持现状、低成本可逆试验、正式投入**。

选择的先后顺序：
1. 目标、硬约束和不可恢复损失；
2. 参考类和可检验的优势来源；
3. 反事实与机会成本；
4. 哪个未知能改变选项排序（VOI）；
5. 依据可逆性决定证据门槛；
6. 何时继续、退出或废弃假设。

即使收益期望看似为正，若可能进入不可恢复的失败状态，应优先约束风险。**凯利只适用于存在可验证 Edge 且概率与赔率估计可靠的场景，绝不能为了填表强算仓位。**

## 六、反错机制：五种必须主动检查的偏差

- **幸存者偏差**：只看见成功样本，缺失失败总体。
- **叙事拟合**：事后解释漂亮，事前没有可结算预测。
- **多重检验**：尝试大量指标后只报告最好的结果。
- **代理指标失真**：热度、分数、排名被当作真实目标。
- **非平稳性**：规则、参与者、流动性和制度改变后，旧统计关系失效。

每次研究至少列出一个最可能推翻自己主判断的证据；重大决策还要记录第二解释。

## 八、三道理论层验收题

1. **新事实检验**：出现一条吸引眼球的新消息，却与当前选项无关。系统应能使用 VOI 明确选择“停止研究”，而不是因为信息多而得出强结论。
2. **反证检验**：一个案例看起来极具吸引力，但参考类失败率高、证据同源。系统应降低信念强度，列出能翻转判断的最小新证据，禁止捏造精确成功率。
3. **生存检验**：一项操作均值正但存在出局路径。系统应指出非遍历风险；即使故事诱人也不能将“高期望”自动转换成“应该执行”。
