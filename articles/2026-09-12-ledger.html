固定研究台账：把研究变成可结算记录

从今天开始，不只保存观点，还固定记录机会状态、验证条件、执行与结果。

1. 固定状态

  • READY：关键条件已验证，进入可执行候选。
  • WATCH：逻辑成立，但价格、催化、流动性或时机尚未满足。
  • RESEARCH：仍有关键事实需要验证。
  • PASS：当前不值得继续投入时间或资金。

2. 每个项目固定记录

日期、项目、链、价格/市值基准、叙事、真实需求、边际买家、催化、流动性、筹码/合约风险、结论、下一步验证、最终结果与复盘。

3. 今日观察池

  • PONS · Robinhood Chain · WATCH：验证费用、回购资金、真实需求与价格传导。
  • STONK · Solana · WATCH：验证平台收入、回购销毁、stock-meme 交易持续性。
  • EMBER · Solana · RESEARCH：验证 Launchpad 使用量、费用结构、真实活跃度。
  • BREW · BNB Chain · RESEARCH：验证平台采用、股票配对需求、竞争格局。
  • Arc 生态 · RESEARCH：验证主网上线后的真实部署、流动性与首批可交易资产。
价格、FDV、成交量、Funding、OI 等动态数据，在每次实际决策时重新读取，不在长期记录里硬编码旧数字。

4. 固定审核顺序

发现 → 身份/团队 → 产品与真实需求 → Token / 费用结构 → 边际买家 → 链上持仓与 LP → DEX/CEX 流动性 → Funding/OI/清算 → 催化 → 风险 → READY / WATCH / RESEARCH / PASS

5. 记录纪律

  1. Distribution ≠ Demand，最终要落到净买盘。
  2. 项目好 ≠ Token 好，Token 好 ≠ 当前价格值得买。
  3. PASS / NO TRADE 也必须记录，避免只记成功案例。
  4. 所有研究结论必须能被后续结果验证。
  5. 没有明确批准，不把研究候选写成真钱仓位。

6. 当前模式

暂不启用自动扫描。先手动使用一段时间，观察哪些数据源真的改变判断，哪些只是增加噪音。
