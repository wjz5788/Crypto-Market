# Cognitive Core v2.0：元认知控制器与可证伪判断协议

> 版本：2026-10-09 · 性质：**理论规范 / 设计研究**，不代表软件已运行。
> 适用范围：复杂解释、预测、选择、学习、设计、组织及长期决策。不是交易策略。
> 依据：用户提供的《万维钢·现代思维工具100讲》原始 SKILL.md v2.0。领域特定执行要求由相应领域 Skill 另行负责。
> 依赖：`docs/theory-core-v1.md`。v2 扩展 v1 的**工具路由、冲突裁决、证据权重、停止机制、理论验收**；不改扫描、Radar、交易及任意运行时代码。

## 0. 关键结论：先判断问题，再选工具

100 个工具不是一个每次运行的长列表。它们是条件性推理程序：问题不同，适用工具不同。对低判断成本的机械任务不激活；对复杂问题仅调取**一个主工具、最多三个角色不重叠的辅助/反证工具**。

对一个问题，底层应输出：
1. 我们实际要判断或改变什么；
2. 哪个模型能改变判断；
3. 现在已知什么、还缺什么，哪些信息可信；
4. 哪一项选择相对基准更好，是否存在不能接受的失败；
5. 哪个观察结果会推翻判断；
6. 哪个最便宜的动作可以带来新证据；
7. 何时停止研究、更新模型或放弃判断。

**原则：理论不是证据；清晰的叙事不是因果证明；准确描述不保证可执行；单次正确不证明长期能力。**

## 2. 一套具体的元认知循环

### G0：是否值得动用理论？

- 简单事实、翻译、机械计算、格式整理：直接完成，不启动理论路由。
- 解释、预测、因果、分歧、方案选择、损失可能不可逆、多个目标互相冲突：进入 G1。
- 情况不清但后果轻微：允许可逆试验，而非要求漫长的理论报告。

### G1：先形成问题地图

最小七元组 `P=(goal, values, constraints, horizon, state, unknown, failure)`。

- `goal`：要提高/降低/解释哪个可观测量？
- `values`：谁的利益、权利和真实目标应计入？
- `constraints`：不可违反的物理、法律、伦理、资金、时间和能力边界。
- `horizon`：一次性决定、循环决策还是长期结构变化？
- `state`：目前在哪一状态；有无反馈和延迟？
- `unknown`：哪个未知足以翻转最佳选项？
- `failure`：常见失败、致命失败、不可恢复失败分别是什么？

如果提问其实包含几个不同问题，应拆分；不可把“预测会怎样”直接等同于“应该怎样做”。

### G2：先按任务定位板块，再选择主工具

**选择标准不是关键词匹配，而是边际决策贡献**：
- 工具能够改变对问题的表述、因果假设、判断阈值或行动排序，才有资格成为主工具。
- 辅助工具按独立工位选择：`mechanism`（解释机制）、`boundary`（检查硬约束）、`counterexample`（质疑主判断）、`action`（设计可逆验证）。
- 辅助最多三个；无增量的工具立即剔除。
- “泛用好词”不算工具：必须指明该工具针对的变量、可观测证据、可否证条件。

**例**（一般项目决策，不涉及任何币）：
- 问题：新服务该不该启动？主工具可选 5.4 机会窗口。
- 辅助：5.5 效果推理（低成本试点）；5.1 经济租（能否留住价值）；3.11 选择偏差（不要只采访愿意试用的人）。
- 若尚未确定用户基本需求，优先检查零阶问题，而非强行套机会窗口。

### G3：建立可审计的认识论账本

每条重要断言写明：
`claim_id / claim / type / source / timestamp / observation_method / uncertainty / alternatives / valid_until`。

`type` 只能明确标为：
- **OBSERVED**：直接观察或有来源的可核验事实；
- **REPORTED**：他人的陈述、报道或数据，尚须确认口径；
- **INFERRED**：依据前提推得，不是原始事实；
- **ASSUMED**：未验证的工作假设；
- **NORMATIVE**：价值判断/目标偏好；
- **UNKNOWN**：决策相关信息缺口。

一个高度流行的说法不能因为被数十篇文章重复而变成数十个独立证据；同源材料要构建**来源依赖关系**。同时记录反面材料和测量误差，不能只收集对自己有利的样本。

**独立性优先于数量**：一条直接观测、有诊断力的证据，可能比许多次转述更重要。证据质量必须与结论的可逆性和损失上限匹配。

### G4：构造至少两个竞争性解释

- H1：当前主要机制成立。
- H0/H2：基准机制、替代机制或反事实解释。
- 列出：若各自成立，**我们预期在可观察结果上看到什么不同**？
- 找最能区分两解释的一条证据，而不是收集更多共同支持它们的材料。

如果没有可区分的预测：该机制目前只是**解释性叙事**，不应升级为已验证的因果结论。

### G5：让数据真正改变信念

1. 先找相近的外部参考类以及被忽略的失败样本；
2. 对证据的诊断性进行判断：`P(evidence|H1)` 与 `P(evidence|H0)` 是否明显不同？
3. 在可信、独立的似然信息存在时，按 `posterior odds = prior odds × likelihood ratio` 更新；若数值缺失，用明示的区间/等级，不造精确概率。
4. 发现证据与旧结论冲突时，先改判断，不为护住旧结论而反复补故事。
5. 不允许把“预测”包装成“已经发生的结果”。

### G6：决策与停止规则

先形成至少两个可行选择，通常为：
`BASELINE / CHEAP_REVERSIBLE_TEST / COMMIT`。

按以下顺序判定：
1. 硬约束与不可承受损失，具有优先于收益优化的否决权；
2. 比较基准方案和真正的替代方案，扣机会成本；
3. 检查参考类、反事实、边际收益与风险；
4. 选择可能改变行动、成本最低的下一证据（VOI）；
5. 新证据的预期决策价值低于获取/延迟/注意成本时，**停止研究**；
6. 若关键未知无法消除且后果难逆，结论为 `ABSTAIN / NO_DECISION`，不是勉强编造答案；
7. 可逆试验只获得**试验许可**，不自动获得扩大投入的许可。

## 3. 理论冲突裁决器

两个工具同时给出不同方向时，使用五问：
1. 是否追求同一个真实目标？
2. 是否观察相同的时间尺度？
3. 一个解释的是群体均值，另一个说的是个人尾部路径吗？
4. 是否假设同一个系统状态和反馈延迟？
5. 一方是否提供不可逾越的硬边界，另一方只是收益优化？

典型冲突：
- **正期望 vs 非遍历性**：一次错误会导致出局时，生存护栏优先；不通过“收益够高”绕过。
- **机会窗口 vs 经济租**：需求窗口好不等于你有收益索取权；若无法价值捕获，维持试验或放弃正式投入。
- **反馈回路 vs 古德哈特**：指标增长可能是正反馈，也可能是刷指标；必须查真实结果与可操纵性。
- **贝叶斯更新 vs 选择偏差**：即使证据看起来很强，如果样本选择机制有问题，不能把更新幅度当作可信结果。
- **OODA 快速迭代 vs 信息价值**：越快并非越好；新增信息不改变行动时应停止，而不是加速无效循环。
- **探索与利用 vs 复利**：继续探索会牺牲短期效率，但无探索又可能长期停留在过时方案；保留适度探索预算，不把任一工具当绝对命令。

冲突不可消除时，报告`CONFLICT_UNRESOLVED`，写下最小裁决证据。

## 4. 世界模型：从相关到机制

任何因果解释应区分：
- `stock`（存量）：能累积并影响下一时刻的状态。
- `flow`（流量）：改变存量的输入、输出、损耗。
- `agents`（行动者）：不等于外部常量；会回应激励改变行为。
- `constraints`（约束）：决定哪些路径不可能。
- `feedback`（回路）：变化是自我增强还是反向校正？
- `delay`（延迟）：行动后多久显现，是否造成误判？
- `confounders`（混杂）：观察到的相关可能源自共同原因。
- `intervention`（干预）：有没有能区分因果链的自然实验或低成本试验？

结构上可以先用有向因果草图表达：`行动 → 中介变量 → 观察结果`；必须写明潜在混杂、可替代机制与数据缺口。

对无法执行随机实验的复杂世界，尽量使用前后对照、分组对照、自然实验与时间顺序约束，但不能承诺自动识别因果。

## 5. 认识论四个危险区

### 5.1 参考类错误
参考类过宽会抹掉机制差异；过窄会被主观挑样本。必须事前定义准入规则，并记录被排除样本。

### 5.2 多重检验与过拟合
试了很多条件后只汇报最好的一项，事后显著性不可信。探索结果标 `EXPLORATORY`，独立样本验证后才标 `CONFIRMED`，并保留全部尝试记录。

### 5.3 分布漂移
当参与者、规则、渠道、制度或测量口径发生变化，旧参考类的适用性需要重审。不能用“历史一直如此”当永恒先验。

### 5.4 证据污染
强烈观点和推荐行动会改变后续数据及参与者行为。区分观察、干预和反馈，警惕模型本身成为系统的一部分。

## 6. 学习论：衡量判断能力，而不是一次输赢

### 6.1 三张账

1. **预测账**：事件定义、概率/区间、截止日期、结算规则；必须在结果产生前锁定。
2. **决策账**：当时已知事实、可选方案、约束、选用工具、执行动作、为什么没有选其他方案。
3. **纠错账**：哪个假设被推翻？是数据错、模型错、目标错、时机错还是执行错？最小规则更新是什么？

切记：**好决策可能碰上坏结果；坏决策也可能侥幸成功**。单例不能裁决模型优劣。

### 6.2 在何时使用量化分数

只有可重复、可结算的二元预测与明确事件定义，才可累计 Brier Score：
`Brier = mean((forecast_probability - observed_outcome)^2)`。
Brier 越小越好，但需要与基准模型对比，也要检查类别频率、难度、样本量、截断样本和时序泄漏。

非二元事件用对应的合适评分方法；主观解释类问题不得硬凑百分比。低样本不声称已校准。

### 6.3 不变的反事实问题

- 若不使用该思维工具，结论会不会不同？
- 是否比简单基准（如维持现状、常识预测或朴素参考类）更有价值？
- 如果剔除最幸运的一次结果，表现还有无增量？
- 系统是否能检测自己不知道的东西（`UNKNOWN`、`ABSTAIN`），而不只是总能给答案？

## 7. 最少推理成本：理论层也有 VOI

将“多思考一点”视为一个有成本的行动：
- 只针对当前问题读取原 Skill 对应工具条目，不反复加载全部 100 条正文；
- 不做跨领域工具堆叠，除非会改变决定；
- 用简洁的事实/反证结构替代重复讲概念；
- 已有判断且没有新的高诊断性证据时，直接复用结论并注明截至时间；
- 关键信息无法得到时及时写 `ABSTAIN`，不要用更长的输出掩盖未知。

## 9. 理论设计的不可变原则

- **事实约束理论**，不反过来拿理论压事实。
- **可观察机制优先于叙事完整度**。
- **底线优先于平均收益**，尤其在不可逆的情境。
- **独立证据优先于内容数量**。
- **信息价值优先于研究数量**。
- **长期校准优先于单次正确**。
- **显式未知优先于伪精确**。
- **用户明确目标与授权优先于 AI 自行设立目标**。
- **思考工具不能自动赋予现实世界行动权限**。

## 10. 下一步（严格不进入应用层）

理论层还需要完成两类纸面验证：
1. **对抗样例**：给同一模型看互相矛盾证据、幸存者样本、难逆损失，检查是否产生恰当 `ABSTAIN` 和修正条件。
2. **消融比较**：移除所选主工具，重跑同一问题；若结论、证据要求、可选动作都毫无变化，则本次工具选择是形式主义。

测试规范单列于 `docs/theory-v2-acceptance.md`；在运行时执行前，不得声称测试已通过。

**禁止阶段漂移**：本 v2 仅是理论建模与验证规范；不新增系统扫描、代币筛选、价格指标、交易授权或 Agent 运行时。
