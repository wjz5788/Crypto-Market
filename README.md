# Crypto Market OS

个人公开 Crypto 市场认知系统。

## v0.1

- 市场温度 Dashboard
- BTC / ETH / SOL / HYPE / PENDLE / JUP / ENA 实时价格卡片
- 机会队列：WATCH / RESEARCH / WAIT
- 真钱仓位区
- 预测账本
- 每日在场日志
- 固定研究与交易规则

## 运行方式

直接打开 `index.html`。

部署到 GitHub Pages 后，页面会尝试从 CoinGecko 公共 API 获取实时价格。

## 日常工作流

和 ChatGPT 讨论 → 形成判断 → “成文并存档” → 写入 `articles/` → 更新机会队列 → GitHub Pages 展示。

## 原则

研究候选不是持仓。
没有用户明确批准，不记录成真实交易。
